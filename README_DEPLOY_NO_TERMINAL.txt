SAU KHI CHAY ON DINH:

1. Tao Scheduled Task trong Windows de chay file Start_GiongRoute_Server.cmd khi khoi dong may.
2. Cau hinh Task chay du voi quyen cao nhat va bat dau khi Windows startup.
3. Mo Windows Firewall cho TCP port 8080.
4. Khi may chu bat, ung dung tu dong chay.
5. May tram truy cap: http://IP-MAY-CHU:8080

Khong can nguoi dung mo PowerShell hay go npm run dev.
